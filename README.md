# Notes Management REST API

This is a Spring Boot project that provides REST APIs for managing notes.

## Tech Stack
- Java
- Spring Boot
- MySQL
- Spring Data JPA

## Features
- Create Note
- Get All Notes
- Update Note
- Delete Note

## API Endpoints
- POST /api/notes
- GET /api/notes
- GET /api/notes/{id}
- PUT /api/notes/{id}
- DELETE /api/notes/{id}

## Run Locally
1. Create MySQL DB: notes_db
2. Update application.properties
3. Run the application
